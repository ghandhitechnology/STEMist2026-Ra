# Sources

This repository previously included code and materials from the **Neural
Transparency** project. That work has been removed from this repo and lives in
its original repository:

- **Neural Transparency: Mechanistic Interpretability Interfaces for
  Anticipating Model Behaviors for Personalized AI**
  https://github.com/mitmedialab/neural-transparency
  Authors: Sheer Karny, Anthony Baez, Pat Pataranutaporn (MIT Media Lab)

The removed components were:

- `interface/` — the original web-based study interface
- `persona-vectors/` — persona/trait vector generation and Modal APIs
- `user-study-analysis/` — the user-study statistical analysis pipeline

Everything currently in this repository (`rauchat/`, `colab/`, and the Gemma
trait-vector protocol) is original work for this project. Please refer to the
repository above for the prior work and cite its authors accordingly.
